# Checkbook Updates

Public macOS releases and update information for Checkbook.

## Availability

The automatic updater is being prepared. No downloadable release has been published yet.

When available, signed app downloads and `appcast.xml` will appear in [Releases](https://github.com/STAGES6020/Checkbook-Updates/releases). The Mac app will offer **Check for Updates…** and automatic update checks.

## Repository contents

This repository is for release binaries, release notes, and the update feed. It does not contain the application's source code, signing private keys, user ledgers, backups, or financial information.

Checkbook's ledger synchronization uses the owner's private iCloud database, independently of these software downloads.
